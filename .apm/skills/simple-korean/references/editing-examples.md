# 한국어 표현 편집 예제

## HTML 힌트와 짧은 구 유지

**원문**

```markdown
_<!-- 이 코드를 잘 모르는 독자도 이해할 수 있도록 변경 내용을 쉬운 말로 120자 이내로 요약합니다. -->_
```

**편집**

```markdown
_<!-- 이 코드를 잘 모르는 독자도 이해할 수 있도록 변경 내용을 쉬운 말로 요약. 길이 <= 120자 -->_
```

강조·HTML 주석·독자·요약 목적·상한을 보존했습니다. `요약·초심자·120자`로 줄이면 독자와 요약의 관계가 사라집니다.

다음 PR 템플릿의 형식·글자 수는 이 예제의 조건입니다. `pnpm check`가 정의된 저장소를 가정하며, 체크박스는 실행 결과가 아니라 앞으로 확인할 항목입니다.

```markdown
#### 배경

<!-- 변경이 필요한 이유. 길이 <= 240자 -->

#### 한 줄 요약

_<!-- 이 코드를 잘 모르는 독자도 이해할 수 있도록 변경 내용을 쉬운 말로 요약. 길이 <= 120자 -->_

#### 변경 사항

- <!-- 변경 사항을 항목별로 정리 -->
- <!-- 핵심 내용 위주 -->
- <!-- 각 항목 <= 120자 -->

#### 검토한 대안

- <!-- 검토한 대안과 채택하지 않은 이유 -->

#### 테스트 계획

- [ ] `pnpm check`
- [ ] <!-- 변경 사항에 필요한 추가 검증 항목 -->
```

## 다른 조건은 분리

**원문**

> 운영자 승인 후 삭제합니다. 보존 대상은 삭제하지 않습니다. 파일 크기는 10 MB 미만이어야 합니다.

**잘못 줄인 예**

> 운영자·승인·삭제·보존 대상 제외·10 MB 이하

승인 주체·순서가 흐려졌고 `< 10 MB`가 `<= 10 MB`로 바뀌었습니다.

**편집**

- 운영자 승인 후 삭제
- 보존 대상 삭제 금지
- 파일 크기 < 10 MB

승인 후 삭제라는 순서는 한 항목에, 삭제 예외와 크기 제한은 별도 항목에 남겼습니다.

## 짧지만 다른 뜻인 표현 구분

| 원문                                             | 편집                                   | 바꾸면 안 되는 표현                                |
| ------------------------------------------------ | -------------------------------------- | -------------------------------------------------- |
| 명령을 아직 실행하지 않았습니다.                 | 명령 미실행                            | 실패: 실행한 적이 있다는 뜻이 됨                   |
| 반환값을 수정할 수 있는지는 확인하지 못했습니다. | 반환값 수정 허용 여부 미확인           | 반환값 수정 금지: 없던 금지가 생김                 |
| 연결이 끊기면 일부 기록이 남을 수 있습니다.      | 연결이 끊기면 일부 기록이 남을 수 있음 | 기록 없음 또는 기록이 남음: 가능성이 확정으로 바뀜 |

`최대 크기 근처에서 실패`만으로 `<`와 `<=`를 정하지 않습니다. `적절히 처리합니다`는 실패 시 임시 파일을 삭제한다는 근거가 있을 때만 `실패하면 임시 파일을 삭제합니다`로 바꿉니다.

## 참고 범위

[국립국어원 쉬운 공문서 쓰기 길잡이(2022)](https://www.korean.go.kr/front/etcData/etcDataView.do?etc_seq=700)는 독자 관점과 정확한 표현의 참고 자료입니다. 공문서용 안내이지 한국어 통제 언어 규격은 아닙니다. 공공누리 제3유형(출처표시·변경금지) 자료이므로 원문은 링크로 제공하며 예문을 개작하지 않았습니다.
이 스킬의 구·명사형·수식 선호는 사용자 선택입니다. 외부 자료의 의무 규칙이나 표준 인증 기준으로 주장하지 않습니다.
예제는 자체 작성했으며 외부 자료의 예문·표를 옮기지 않았습니다. 예제의 글자 수는 해당 템플릿의 조건이며 스킬 전체의 길이 제한이 아닙니다.
