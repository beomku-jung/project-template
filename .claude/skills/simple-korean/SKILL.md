# 간결하고 자연스러운 한국어

사용자가 선호하는 기본값은 **뜻이 같은 자연스러운 표현 중 더 짧고 바로 읽히는 쪽**입니다. 문장 수·단어 수를 고정하지 않습니다.
표현 수정에서는 내용·정보 위치·기술 계약·운영 의무를 바꾸지 않습니다.

## 편집 규칙

### 형식은 살리고 표현부터 바꾸기

- 표현만 다듬을 때는 기존 제목·목록·강조·작성자용 HTML 힌트를 유지합니다. 전체 구조를 다시 쓰거나 힌트를 삭제하지 않습니다.
- 제목·표 항목·체크리스트·힌트는 자연스러운 구·명사형을 기본으로 둡니다. 주체·순서·이유를 구로 전달할 수 없으면 문장으로 씁니다. 모든 항목을 `합니다`로 끝내지 않습니다.
- 같은 역할의 제목·항목은 형식을 맞추되 본문까지 같은 어미로 바꾸지 않습니다. `의존성 설치`와 나란한 `설정을 적용합니다`는 `설정 적용`으로 맞춥니다.

### 조건은 의미 관계대로 나누기

- 서로 다른 조건·책임·예외는 별도 문장이나 목록 항목으로 나눕니다. 짧게 만들려고 `·`로 이어 의미 관계를 숨기지 않습니다. 단순 병렬인 `린트·포맷` 같은 표기는 유지할 수 있습니다.
- 순서·선행 조건은 `후`, `전에`, `이면` 등으로 남깁니다. `승인·삭제`로 줄여 승인 후 삭제라는 순서를 없애지 않습니다.
- 수치 조건은 `<`, `<=` 같은 수식으로 씁니다. 대상·단위·비교 방향·경계값 포함 여부가 수식에서 드러나지 않으면 말로 씁니다. 숫자·단위·음수 여부·상한/하한·경계값 포함 여부와 불확실성은 원문대로 보존합니다.

### 같은 개념은 같은 말, 문장은 자연스러운 말

- 같은 개념을 가리키는 말은 기존 용어 하나로 맞춥니다. 서로 다른 상태·대상·책임은 비슷해 보여도 합치지 않습니다. 예: 같은 개념의 `호출 이력`·`호출 기록` → `호출 기록`.
- `수행을 진행`, `진행이 이루어짐`보다 누가 무엇을 하는지 드러나는 동사를 씁니다. `설정 적용을 진행합니다` → `설정을 적용합니다`. 제목이라면 `설정 적용`으로 충분합니다.
- 삭제해도 사실·조건·행동·판단이 같은 문구는 뺍니다. `작업 목적에 맞는 명령을 사용합니다`처럼 선택 기준이 없는 말도 뺍니다. 경고·예외·이유를 담은 반복은 해당 의미가 다른 문구에 남는지 대조한 뒤 줄입니다.
- 금지어 목록으로 단어를 일괄 삭제하지 않습니다. `가능`, `위해`, `진행` 같은 말도 허용 여부·목적·상태를 나타내면 남깁니다.

### 줄여도 의미는 그대로 두기

- 원문에 없는 보장이나 근거를 넣지 않습니다.
- 사실·가정·제안·미확인을 구분합니다. `허용 여부 미확인`을 `허용하지 않음`으로, `실패할 수 있음`을 `실패함`으로 바꾸지 않습니다.
- 부정·금지·필수/선택·승인 주체·예외·완료 시점·소유권을 남깁니다. `명령 미실행`은 실행 상태이며 `동작 미확인`과 같은 뜻이 아닙니다.
- 식별자·경로·명령·오류 메시지·코드 리터럴은 실제 표기를 유지합니다. 인용문·정해진 명칭은 두고 주변 설명만 다듬습니다.
- 원문이 모호하면 제공된 근거에서 주체·조건을 찾습니다. 근거가 없으면 모호한 지점이나 미확인 상태를 남깁니다.

## 짧은 편집 예

| 원문                                                          | 편집                                      | 보존할 의미           |
| ------------------------------------------------------------- | ----------------------------------------- | --------------------- |
| 파일 크기는 10 MB 미만이어야 합니다.                          | 파일 크기 < 10 MB                         | 10 MB 제외, 단위 유지 |
| 대기 시간은 0밀리초 이상 5000밀리초 이하입니다.               | 0 ms <= 대기 시간 <= 5000 ms              | 양끝 포함             |
| 운영자가 승인한 뒤 삭제합니다. 보존 대상은 삭제하지 않습니다. | 운영자 승인 후 삭제. 보존 대상 삭제 금지. | 승인 주체·순서·예외   |
| 반환값을 수정할 수 있는지는 확인하지 못했습니다.              | 반환값 수정 허용 여부 미확인              | 허용·금지 모두 미확정 |
